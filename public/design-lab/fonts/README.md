# Local typography research assets

**UNSELECTED EXPLORATIONS. Production license verification required.**

These are the original font files served by Typeface.ge, retained for the explicitly requested local design comparison. They are not covered by the main application's Noto SIL OFL notices. No font binary was modified or subsetted. `sources.json` records direct asset URLs, catalog pages, byte sizes, SHA-256 checksums and inspected variable axes. `embedded-notices.txt` preserves embedded copyright, author and license records.

The collection contains 12 candidate families plus NeoBau's real Bold face. Only referenced faces are fetched by browsers. The typography comparison intentionally loads all candidates; ordinary application routes load none of these files.

Some embedded records explicitly say free or describe commercial use; others contain copyright text without a grant. Catalog badges are not treated as conclusive production webfont/distribution licenses. Verify the exact chosen versions, embedding, redistribution and any upstream/adaptation rights with their creators before shipment. No candidate was excluded from visual comparison because of missing site metadata.

See [the exploration report](../../../docs/design-exploration.md) for specimen observations and functional font roles. Keep all notices with these local assets. This asset folder is not a production font package.
