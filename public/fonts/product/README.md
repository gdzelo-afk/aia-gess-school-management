# Selected product typography

Mersad Variable is the selected Georgian interface/display family. MCh NeoBau Regular/Bold is reserved for numerical display (dates, times, counts, years and identifiers). GL Tatishvili 12 Normal is reserved for the dashboard greeting. Its original file was obtained from the user-specified Typeface.ge page. All binaries remain unmodified; no main route imports design-lab code, styles or font URLs.

Source URLs, sizes and SHA-256 checksums are preserved in `sources.json`; embedded copyright/author notices are preserved verbatim in `embedded-notices.txt`. This selection was explicitly authorized during design convergence. **Production license verification required** for embedding, redistribution and the exact binaries before external distribution. No candidate was excluded merely because catalog metadata was incomplete. Noto OFL notices in the parent directory cover only the separate Noto fonts.

Font faces use `font-display: swap`. Regular/Bold NeoBau files are separate actual weights, not a variable-font claim. Tatishvili is preloaded by the main entry to stabilize the greeting; the other faces load when used. No remote font service or new npm dependency was introduced.
