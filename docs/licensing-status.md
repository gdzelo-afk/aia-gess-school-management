# Licensing, ownership and third-party status

Reviewed 22 October 2026 against accepted master `6cdf9b5` and the repository-readiness changes. This is an evidence/status record, not a new license grant or a definitive legal ownership opinion.

## Original application

The repository is intentionally publicly viewable. The original AIA-GESS application has **not** been released under an open-source license. Copyright and other applicable rights remain with their respective rightsholders. Public visibility does not independently grant general modification, redistribution or sublicensing rights; GitHub's platform viewing/forking terms and applicable law remain relevant. See [GitHub's licensing explanation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

Maintainers identify the student development team as the authors of the project. The repository does not establish exclusive ownership by a named person, school or legal entity. Git author/automation identities, repository administration and possession of files are not assignments of copyright. No contributor agreement, school assignment or comprehensive ownership ledger was found.

The package retains `private: true` and uses `license: "UNLICENSED"` following [npm's convention](https://docs.npmjs.com/cli/v11/configuring-npm/package-json/#license). This prevents accidental npm publication and records that no package reuse license is granted. It is not the permissive **Unlicense**, not an open-source SPDX grant and not a GitHub visibility control. No application LICENSE file or open-source license has been added.

Maintainers must verify and retain privately, where appropriate:

1. Who authored each contribution and has authority to permit its present publication; include contributions made with automation or incorporated from elsewhere.
2. Contributor permissions and any school, employment, educational or contractual restrictions. Do not assume a school's rollout approval transfers copyright.
3. Rights for public source redistribution as distinct from use inside a hosted preview, particularly fonts and school branding.
4. Accurate attribution and permission scope before any relicensing or independent tool release. Do not publish individual student identities or private agreements without permission.
