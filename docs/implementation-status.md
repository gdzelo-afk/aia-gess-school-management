# Implementation status

Foundation implemented 27 September; selected frontend continued 28 September 2026. This is a local development foundation, not a production EMS release.

## Stage 1A — current implementation, 29 September 2026

Academic Structure + People / Onboarding is complete for the agreed Stage 1A local/demo scope. The historical foundation/design verification below describes earlier states and does not replace Stage 1A verification.

- **Academics:** `/academics` manages draft/current/archived academic years, two semesters, grade levels 1–12 and sections, subjects, core/elective offerings, teacher/homeroom assignments and dated rosters. `/calendar` manages normal holiday/vacation/milestone records. Used identities and historical periods are protected; future years are configurable.
- **People:** `/students` retains scoped search/filter/sort/detail and adds creation, versioned profile edits, enrollment transfer/end/return, archive/restore, multiple guardian links and effective history. `/guardians` locates/creates people and shows family history; links/end dates are managed from a student. `/staff` manages profile/employment, departure and assignment history. Async bounded selectors distinguish existing identities without automatic merging.
- **Accounts:** `/accounts` provides authorized invitation, role management, recovery/reinvite and disable. `/activate` consumes an expiring single-use token and sets a Better Auth password; `/recovery` gives a generic response and local delivery. There is no public registration, email provider or MFA UI. Local links are available only in non-production demo mode; production issuance remains unavailable pending a provider.
- **Integrity:** reviewed migrations `0002`/`0003`, version conflicts, one transaction/administration lock per mutation, date-only overlap/bounds triggers and atomic audit. Existing identities, local data and enrollment/assignment history are preserved. Ending relationships/employment removes access; guardians receive equal normal rights on newly linked relationships while independent existing finance/academic flags remain enforced.
- **Demo calendar:** validated supplied JSON becomes 21 calendar rows plus the configured 2026–2027 year and semesters. Inclusive source ends are converted to exclusive boundaries in Asia/Tbilisi date semantics. Contradictory grade-1/12 teaching-day totals are recorded as warnings, not promoted to policy. Seed upgrades known fictional records once and preserves later administrator edits.
- **Design:** existing evolved Vector A, lens, Tatishvili greeting/cursor, command palette, themes and archive remain. New operations use the same main tokens with focused review dialogs, dense lists and contextual histories. Sidebar semester progress uses current Tbilisi date and configured active-year semester dates; gaps/unavailable configuration show a neutral state. The block remains immediately after navigation.

**Still deferred:** Stage 1B Timetable, attendance, gradebook, publications, operational finance, messaging, admissions, other EMS modules; production email delivery, MFA and launch hardening. MFA should use Better Auth TOTP/recovery-code integration with complete security tests. No production-readiness claim.
